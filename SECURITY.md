# Security and privacy

This repository is documentation, not a deployable production configuration.

Do not add credentials, private documents, personal identifiers, production paths,
network addresses, raw logs, state databases, model artifacts, backup archives, or
configuration copied from a live system.

Examples must use generic component names and relative paths. Descriptions should explain
the engineering pattern without revealing a currently exploitable endpoint or unresolved
private defect.

Security concerns should be reported privately to the repository owner. Do not open a
public issue containing a secret or private operational detail.
