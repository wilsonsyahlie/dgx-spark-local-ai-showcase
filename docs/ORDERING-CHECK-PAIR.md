A previous frozen experiment passed its selected tests, but independent source review found a dependency-wave ordering violation. Children entered later waves in parent release order rather than their own original input order. For roots a and b followed by child c of b and child d of a, the saved implementation produced a, b and then d, c; the contract requires c, d in that second wave. This continuation reproduced the defect by executing an exact copy in a new isolated diagnostic workspace. The original source and historical scores remained unchanged; the old implementation was not repaired.

The new acceptance design directly covered conflicting release and input order across multiple waves. Seventeen supplied scenarios and forty-three independent cases retained validation, reserved identifiers, harmless function-valued extras, no mutation and named-export checks. Twenty-four cases enumerate all input permutations of a declared four-node dependency structure. Two independently implemented correct references, nine targeted faulty implementations, missing and direct exports, and the exact copied old implementation formed fourteen qualification controls. Each ran through the hidden grader, a typed grader of every supplied expression, and the actual canonical checker. Both new checkers rejected the old bug on an identified ordering case; both correct references passed.

Exactly one fresh matched pair then compared the existing workflow with the supplied checker plus explicit usage directions. The order was baseline first. Both arms kept the same eight-step ceiling, model, output allowance, sampling and tools. Neither received the previous implementation, diagnostic transcript, correct references or hidden cases. The trial allowed two one-shot jobs, sixteen accepted requests and a five-minute cumulative worker-time cancellation threshold, with polling and cleanup/settlement overrun possible. No retries, coaching, replacements, historical rescoring, production adoption or automatic further trial were allowed. This was a failure-informed focused test, not an untouched benchmark.
