# A finished transfer can still be an unfinished request

An episodic media recovery exposed several independent holds. A pack used a different numbering scheme, subtitle metadata failed the existing dialogue rule, and successful-grab history prevented ordinary replacements even though the library files were absent.

A decoder failure needed a separate experiment. Keeping the file, streams and execution environment fixed, random-seek samples emitted a specific reference error while sequential decoding to the same windows passed strict checks. The resulting verifier retries only that narrow, bounded case. It preserves the original failure and still requires clean decoding, complete packet coverage, native-language speech, English dialogue and matching media bytes within the original deadline.

Qualification included a full real-file proof, clean samples from other codec families and rejection of truncated inputs. The latter is limited evidence, not a claim to detect every kind of corruption. Reviews and actual-file drift tests preceded staged activation with preserved ownership, backups, pointer-last publication and consumed-action protection. A fresh process and a natural scheduled execution confirmed the deployed policy.

Separately, positive episode identities repaired the numbering issue. A supported failure acknowledgement released the native replacement search without deleting the retained source or changing the verified installed copy. Actual replacement transfers followed.

The narrow verifier repair was deployed; remaining pack imports and human playback were still open at this checkpoint. Transfer, qualification, import and availability need their own evidence. The response kept existing ownership and content checks rather than adding another recurring repair loop.


## A subtitle label was mistaken for an audio label

A later observation found another independent hold: a release title advertised English subtitles, and the acquisition parser inferred English audio. A complete donor file had separately passed native-language speech and English-dialogue checks. A narrow acquisition-rule correction was tested against the exact native engine in isolation, then checked again after activation. Sixteen cases kept explicit wrong-audio claims and wrong-subtitle penalties blocked while allowing the subtitle-only marker. Physical content checks stayed mandatory.

A partial donor pack also required positive separation of installed episodes from missing ones. Duplicate donor files were retained, backed up and excluded from video discovery without altering their bytes or the installed copies. The native preview then exposed only missing targets. Another source could not be parsed and entered the ordinary replacement search; no episode identities were guessed. The overall request was still incomplete.


A second measured reference-message combination exposed a classifier gap at the tail sample. The body-only evidence had initially been mistaken for evidence about the later stage; that inference was superseded by exact tail commands and retained diagnostics. The same tail passed strict sequential decoding with stable full media bytes. A narrow classifier extension still requires the original reference error, bounded diagnostics, completed progress and a clean origin decode. Thirteen focused tests and a full real-file proof passed before two reviews and pointer-last promotion. Other codec paths were unchanged. A fresh process checked the deployed artifact, a natural scheduled run read the new policy, and an earlier installed proof remained valid. This qualifies the narrow correction, not every file in the batch.
