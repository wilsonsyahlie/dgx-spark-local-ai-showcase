# A smaller model still had to earn the switch

A smaller local image reviewer was tested after a larger candidate proved slow and unreliable. The trial fixed quality and latency requirements before observing answers and used the same six image questions for both models.

The candidate noticed a cropped head and read a text fixture. It still called a bicycle a motorcycle, missed a visible scarf and invented missing interface elements. Even a correct identical-image verdict included an unnecessary wrong vehicle label. The selected requests took substantially longer than the baseline, with cold-start and answer-length limitations reported separately.

Resource checks, coexistence and cancellation passed, but some host swapping and pressure stalls remained visible. A successful load was not treated as proof of a useful upgrade. The original reviewer was restored and verified through the real assistant workflow.

The model was not promoted. The value of the trial was enforcing a decision gate and preserving negative evidence. This retrospective includes no production configuration, live topology, private images, identifiers or deployment instructions.
