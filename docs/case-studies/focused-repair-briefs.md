# Check the handoff before blaming the worker

A long repair request produced a large source rewrite and a new test suite before reaching its deadline. A later, assisted correction finished much sooner. Those were different tasks, so the elapsed times do not establish a speedup. Read-only discovery confirmed that a targeted editing tool was already installed and exposed. The earlier brief combined immutable versions with a prohibition on patching, without explaining the available copy-then-edit route.

The next question is narrower: does focused repair guidance help an ordinary request that already permits targeted edits? A bounded pair uses identical synthetic regressions, an unchanged fourteen-case independent checker, the same worker settings, isolated workspaces and equal preservation requirements. One arm receives only additional guidance to reuse the implementation and existing checks. Both have fixed four-minute deadlines; no coaching, retries or extensions are allowed. Correct completion and demonstrated backups are prerequisites for comparing elapsed time.

The frozen threshold is at least25percent lower whole-task elapsed time. Fixed order, cache and shared-profile effects remain limitations. Even a passing pair supports only a promising task-scoped result, with no global instruction promotion or general performance claim. Existing conversations, protections, reasoning settings and model selection remain outside the change.

Result: rejected. Ordinary guidance completed in116.65seconds and focused guidance in94.71seconds, a raw18.81percent reduction below the frozen25percent gate. Both passed all fourteen independent checks, preserved protected tests/documentation and settled. Both also made two edits with only an initial backup, so neither met the mandatory per-edit preservation gate. No global instructions or defaults changed. Existing conversations and settings were preserved; the same backend finished healthy and idle. Ordered write evidence, backup artifacts and failures are retained. The next reliability candidate concerns structural per-edit protection, separately scoped and reviewed.
