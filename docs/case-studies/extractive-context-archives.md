# Remove generated summaries from the critical continuation path

The user retried a long tool conversation after a summary-recovery change had been declared fixed. It failed again, after substantial summarization time: both output allowances were exhausted. Earlier focused tests had passed, but they had not qualified the entire real multi-chunk caller. The prior completion claim is superseded by this recurrence.

The new compactor makes deterministic excerpts instead of asking a model to summarize. It retains every received user instruction verbatim, leaves current instructions and recent complete tool exchanges intact, and marks shortened older assistant and tool text explicitly. A private exact local archive preserves the complete received source for selective recovery. Recorded commands remain historical data rather than actions to execute again. Native tokenizer counts enforce the context budget without any summary-generation call.

Archive publication is atomic and never overwrites an existing content-addressed record. Files are private to the service owner and verified before reuse. A fresh compactor instance can recover from the same archive without a model call. Prepared preimages remain retained; no deletion or cleanup policy was silently introduced. Exact source snapshots consume storage, and older working excerpts are still lossy.

Verification now separates the paths. Complete saved-task source was processed through the deployed compactor and produced a real streamed response. A labelled read-only turn in the actual failed chat also completed and survived refresh and a narrow-screen check. The native interface independently created its normal context checkpoint before that turn, so the short GUI reply alone was not counted as proof of above-threshold gateway compaction. Preservation checks distinguished that derived checkpoint and the appended diagnostic link from unchanged original content and tool records. Existing host-tool authority could read the private archive, and model processes remained resident through activation and idle observation.

The repair removes a measured failure boundary rather than repeatedly increasing summary limits. It does not prove completion of the original application task, full-window answer quality or endurance. The lesson is to qualify the actual caller and complete source, identify independent preprocessing layers, preserve exact recoverable data, and correct earlier broad claims when real user evidence contradicts them.
