# Research completion with capability-aware guidance

A local research agent ended a turn by printing an unsupported command invocation instead of returning findings. Its role had search tools, not terminal access. Earlier search calls executed, but page extraction repeatedly failed because the selected extraction provider was unavailable. The agent continued searching until its budget ended. The displayed command was not executed.

The repair stayed within the researcher role. Durable guidance now distinguishes tool schemas from actual provider availability, uses the working search capability, stops retries against unavailable extraction, bounds ordinary research to three focused search batches, and reserves a normal cited answer with explicit uncertainty. Search snippets are described as snippets; they do not become claims that a page was opened. Permissions, local inference, model settings and other roles stay unchanged. No cloud credential or terminal capability was added.

Activation initially encountered an expired runtime reference. A separate check then inspected a lazily resumed session before its prompt had been built; that premature assertion failed and was preserved. Source inspection confirmed that a disconnected transport can reap its idle sessions. The corrected verification holds one connection across resume, one accepted follow-up, completion and prompt export. No uncertain submission was replayed.

A successful first continuation still exposed a stale persisted prompt: normal completion alone did not prove durable instruction activation. The exact idle session’s prompt metadata was invalidated through the native state API after a consistent backup, allowing its next native turn to rebuild in the correct role context without changing messages. Verification checks the built prompt rather than merely the source file, preserves all existing history columns, compares configuration hashes and examines actual tool and final-answer records. The supported follow-up uses search, avoids unsupported commands and unavailable extraction, and reports evidence limits. Independent review and protected predecessors qualify a bounded researcher workflow; they do not guarantee universal model compliance.

A separate core finalization edge remains outside this repair: raw content can survive an empty-response retry when the iteration budget ends. That finding is retained rather than hidden or claimed fixed by role guidance. Broad fault injection, physical-device acceptance and long-term recurrence are untested. This retrospective omits production artifacts, identifiers and operational commands.
