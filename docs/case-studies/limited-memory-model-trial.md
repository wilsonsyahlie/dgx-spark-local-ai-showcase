# A large local model on a consumer GPU with limited host memory

The authorized experiment was a standalone installation and short local trial of Strata, an inference engine for a large mixture-of-experts model. It did not replace an existing worker, promote a model or add cloud inference. A private environment and publisher-verified model downloads separated the candidate from established services.

An unloaded model inventory was insufficient exclusion: the existing model router could load on demand and its supervisor could restart it. The bounded experiment held the existing cooperative GPU lock, suspended only the exact idle process chain with retained identity handles, and placed the candidate inside a Windows process job atomically at creation. Normal cleanup proved the owned job empty and device memory released before resuming the same original processes and releasing the lock. Control tests covered inherited descendants, identity rejection, process closure and controller disappearance. They did not establish uninterrupted exclusion following abrupt owner death; simultaneous monitor failure could still require manual recovery.

Preparation exposed transport and test assumptions. Validated parallel byte ranges resolved a slow download while preserving the original partial and checking the complete publisher hash. A mistakenly broad backup transfer was stopped by exact process identity; future receipt transfer uses an explicit artifact allowlist. Windows virtual-environment redirectors created more descendants than assumed. A retained process handle also keeps a terminated process object observable: a signaled handle and empty job provide stronger closure evidence than process-identifier existence.

The first launch failed before loading because detached Python standard streams still referred to invalid handles. Assigning actual file-backed text streams passed a control under the same atomic detached launch. A later full-resident initialization crossed the unchanged free-memory floor during mapped cache filling. It stopped before readiness and was not an observed out-of-memory crash. Source-supported expert budgeting and unbuffered reads changed the loading behavior without weakening the external safety floor. Effective engine logs, rather than configuration flags alone, established the active path.

The successful short trial loaded the requested context capacity and answered arithmetic correctly. Its initial coding response violated a permitted-function restriction. One explicit correction passed all nine independent cases and input-preservation checks with the original assertions intact. Generated code ran in a separate contained job with a short execution deadline and memory limit; actual infinite-loop and allocation-refusal controls qualified that helper. The passing correction does not erase the first instruction-following failure.

The requested host expert cache was clamped to zero by insufficient Windows commit headroom, even though physical RAM remained available. Native logs confirmed the effective path: GPU caching and unbuffered disk reads, with no resident CPU expert copy. The short successful run therefore did not demonstrate the requested host-cache allocation, and its speed depends on the tested disk path. Requested budgets and free physical RAM cannot substitute for measured effective allocation.

Two short coding outputs reported about twenty-six and seventy generated tokens per second; end-to-end response times were approximately six and two seconds. Periodic resource samples showed about thirty and a half GiB of whole-device usage at their maximum, while at least fourteen and a half GiB of system memory remained available. These values are sampled system totals and short-task observations, not exact model allocation, sustained throughput or a quality ranking.

An actual browser conversation passed desktop and narrow layouts, visible loading state, duplicate-submit prevention and refresh retention without page errors. Normal shutdown restored the original process identities and idle service state. The candidate was retained but stopped after the experiment. Full-context recall, large projects, vision, parallel use, physical-device behavior, display-driver stability, reboot and full guardian fault injection remain unqualified. This retrospective contains no deployable configuration, operational commands, private artifacts or current service topology.
