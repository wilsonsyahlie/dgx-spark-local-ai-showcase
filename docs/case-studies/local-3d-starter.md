# A reusable scene foundation, with an unproven speed benefit

A scene-generation experiment introduced a small local 3D foundation with licensed rendering dependencies, camera controls, responsive framing and deterministic animation hooks. A create-only copier refused existing destinations and checked a fixed source inventory. The aim was faster complete tasks without sacrificing correctness; automatic guidance would be retained only after a matched comparison met a preset improvement threshold.

Independent tests inspected actual rendered output at two viewport widths. They exercised motion, pause, resume, reset and camera interaction. Five broken variants exposed weaknesses in an earlier oracle, including a reset check that had accidentally corrected the pose before observing it. The strengthened positive fixture passed ninety-six observations. The shipped example and qualification fixtures remained distinct.

The first ordinary agent task discovered the staged foundation itself and produced a correct scene. That discovery limited what the comparison could establish: it was no longer a clean test of having a library versus having none. More decisively, a new request-tracking record remained unclosed after the task ended. The agreed gate stopped the second arm. The record was not silently reconciled, and automatic guidance was not promoted. No speed gain was established.

The task also exposed a real loading race. A separate browser fixture had allowed more startup time than the actual publishing workflow, so apparently successful checks had missed controls becoming available too late. A minimal module-entry change tied initialization to page readiness. The unchanged production browser checks rejected the original and accepted the repaired fixture at both widths, including a bounded delayed-network diagnostic. Rendered controls and visible failure/retry recovery also passed.

The result was useful bounded functionality, with a deliberately incomplete performance claim. The repaired revision had no matched native timing qualification. Unknown tracking ownership, an early candidate backup gap and an unexplained aggregate test invocation failure remained documented. No arbitrary-scene quality, physical-device coverage or general speed improvement was inferred from the finite controls.

The engineering lesson is to test the actual loading boundary and keep three claims separate: a scene can be correct, its requests can still be unsettled, and its speed benefit can remain unknown. This is a retrospective engineering story, not an operational guide.
