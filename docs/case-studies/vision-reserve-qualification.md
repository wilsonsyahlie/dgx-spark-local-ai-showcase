# Fitting in memory did not make the model a better reviewer

A larger local image reviewer loaded but was interrupted by a free-memory reserve during its third question. The failure was a policy cutoff, not an observed exhaustion of all memory. The owner explicitly approved a bounded experiment with a smaller reserve.

The experiment retained the other resource and ownership protections. Focused tests replayed the rejected sample under both policies. Actual image questions, coexistence, cancellation and restoration then completed. Observation distinguished memory-pressure stalls and reading old swapped pages from new swap-out; a successful short trial was not presented as proof of safety under every future load.

The model still called a bicycle a motorcycle and made questionable reference comparisons. It correctly noticed a cropped head, while a headwear label remained ambiguous. The selected questions also took substantially longer than the baseline. Those outcomes did not justify changing the regular model.

An early assumption that file size alone proved runtime memory fit was explicitly corrected using actual accounting. Separate monitoring concerns were documented without expanding the trial into unrelated repairs. The original reviewer was restored and checked through the real assistant workflow.

This retrospective records a useful resource-policy experiment and a rejected promotion. It includes no production configuration, live topology, private images, identifiers or deployment instructions.
