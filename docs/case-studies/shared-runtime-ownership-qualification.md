# Preserving workload ownership while changing a local inference engine

An agent setup was migrated to a published speculative decoding engine using verified language and vision artifacts. Supported profile and saved-session methods preserved earlier conversations while changing model routing. The engineering challenge was to keep workload ownership intact across a different native server interface.

A bounded adapter registered work before preparation and waited for native execution to unwind before acknowledging cancellation. Unknown ownership and timeouts remained uncertain. Equivalent busy metrics preserved an existing reconciliation probe. A sandboxed lifecycle controller required a fixed local service-bus route; the failed initial dispatch was retained and the sandbox stayed intact.

A first startup passed functional checks but was later stopped by a zero-owned-swap watchdog. The original limit was not captured before ephemeral removal, leaving the cause unproven. Subsequent qualification captured actual zero swap limits and zero owned swap. An explicitly approved release of an idle model improved headroom. No watchdog threshold or global swap policy was weakened.

Actual text, reasoning, tool results, synthetic vision, prefix reuse and bounded concurrent requests passed. Agent-role desktop turns and exact cancellation with a surviving request were observed. A failed role turn remained in the record alongside a distinct later success. Authentication failures and unknown requests failed closed.

These are bounded functional results, not a speed, full-context, quality or refusal-free guarantee. Reboot, physical acceptance and exhaustive UI failure cases were not tested. The owner waived further independent reviews; the record distinguishes that waiver from a passed review. This retrospective contains no current private topology, artifacts or deployable instructions.

The main assistant also completed a real desktop turn and saved-session reopen. An initial reopen observation confused connection and durable session identifiers; it was corrected without another generation. A long background request retained an uncertain accounting slot after cancellation timeout. Once all native work was idle, only that setup-check slot was reconciled through the existing authority-owned absence probe; unrelated historical debt was preserved, and a later actual request completed.
