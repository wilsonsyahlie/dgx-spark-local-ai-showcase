# More correct details did not justify a model switch

A local vision candidate was tested against an existing image reviewer using the same six frozen image questions. The questions covered reference differences, cropped framing, accessories, text reading and an identical-image control. Visible evidence defined acceptance before the models answered.

The candidate completed four cases correctly compared with two for the baseline, yet still called a bicycle a motorcycle and mistook part of the bird for a storage box. Those errors mattered more than a reassuring aggregate score. The candidate was not promoted.

A runtime image-budget warning prompted one bounded configuration repeat. Removing the warning changed neither the answers nor the reported prompt-token counts. Requested limits did not prove equivalent visual detail. A slow first comparison also prevented presenting faster later responses as a broad speed improvement.

The trial checked coexistence with the main assistant, active-request cancellation, exact owned cleanup and restoration of the original reviewer. Focused failure-ordering tests supplemented actual lifecycle evidence; abnormal owner death and automatic deadline expiry were not induced. A separately discovered production ordering concern was documented without expanding the trial into an unrequested repair.

The lesson is to preserve wrong answers, investigate effective settings, and let the required task decide promotion. This retrospective contains no production configuration, private images, live topology, identifiers or deployment instructions.
